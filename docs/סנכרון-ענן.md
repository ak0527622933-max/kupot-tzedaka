# הפעלת סנכרון ענן עם Supabase (חינמי)

מדריך להקמת בסיס נתונים משותף כדי שכל המתרימים יראו את אותם נתונים במכשירים שונים.

## שלב 1 — יצירת פרויקט Supabase

1. גשו ל-[supabase.com](https://supabase.com) ולחצו **Start your project**
2. התחברו (אפשר עם חשבון Google)
3. לחצו **New project**
4. תנו שם לפרויקט (לדוגמה: `kupot-tzedaka`), בחרו סיסמה לבסיס הנתונים ושמרו אותה במקום בטוח, בחרו אזור (Region) קרוב — לדוגמה `Europe (Frankfurt)`
5. לחצו **Create new project** וחכו כדקה שהוא יוקם

## שלב 2 — יצירת הטבלאות

1. בתפריט הצד השמאלי לחצו על **SQL Editor**
2. לחצו **New query**
3. הדביקו את כל הקוד שלמטה, ולחצו **Run** (או Ctrl+Enter)

```sql
create table if not exists holders (
  id text primary key,
  name text not null default '',
  phone text not null default '',
  address text not null default '',
  city text not null default '',
  area text not null default '',
  notes text not null default '',
  deleted boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists collectors (
  id text primary key,
  name text not null default '',
  phone text not null default '',
  deleted boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists boxes (
  id text primary key,
  serial text not null default '',
  holder_id text references holders(id) on delete set null,
  type text not null default 'רגילה',
  status text not null default 'available',
  placed_date date,
  notes text not null default '',
  deleted boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

create table if not exists collections (
  id text primary key,
  box_id text references boxes(id) on delete cascade,
  collector_id text references collectors(id) on delete set null,
  date date not null default current_date,
  amount numeric not null default 0,
  outcome text not null default 'collected',
  receipt_number integer,
  notes text not null default '',
  settled boolean not null default false,
  deleted boolean not null default false,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

alter table holders enable row level security;
alter table boxes enable row level security;
alter table collectors enable row level security;
alter table collections enable row level security;

create policy "app access" on holders for all using (true) with check (true);
create policy "app access" on boxes for all using (true) with check (true);
create policy "app access" on collectors for all using (true) with check (true);
create policy "app access" on collections for all using (true) with check (true);
```

אמור להופיע "Success. No rows returned" — סימן שהטבלאות נוצרו.

## שלב 3 — העתקת המפתחות

1. בתפריט הצד לחצו על **Settings** (גלגל שיניים) → **API**
2. תעתיקו שני דברים:
   - **Project URL** (נראה כמו `https://xxxxxxxxxxxx.supabase.co`)
   - **anon public** key (מחרוזת ארוכה תחת "Project API keys")

## שלב 4 — חיבור באפליקציה

בכל מכשיר שבו תרצו שהאפליקציה תסתנכרן:

1. פתחו את האפליקציה → **הגדרות**
2. תחת "סנכרון בין מכשירים" הדביקו את ה-URL וה-anon key
3. לחצו **בדיקת חיבור** לוודא שהכל תקין
4. לחצו **שמירה והפעלה**

חוזרים על שלב 4 בכל מכשיר נוסף (עם אותם URL ומפתח בדיוק). מרגע זה, שינוי במכשיר אחד יופיע אצל כולם תוך דקה (או מיד עם פתיחת האפליקציה).

## חשוב לדעת על אבטחה

ה-URL וה-anon key **לא** נשמרים בקוד הפומבי באתר — הם נשמרים רק במכשיר של כל משתמש, לאחר שהוא מדביק אותם ידנית במסך ההגדרות. כך שמי שרק פותח את האתר לא רואה אותם. אבל כן — כל מי שיש לו את ה-URL והמפתח (כלומר, כל מתרים שחיברתם) יכול טכנית לגשת ישירות לנתונים דרך הרשת, לא רק דרך האפליקציה. לצוות קטן ומוכר של 1-3 מתרימים זה סביר לגמרי; אם בעתיד ירצו הרשאות נפרדות לכל מתרים (למשל שמתרים יראה רק את המסלול שלו), זה שדרוג נפרד שידרוש גם מסך התחברות באפליקציה.
