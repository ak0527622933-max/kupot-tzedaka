# איך מעלים את האפליקציה לאינטרנט (בחינם, בלי תכנות)

מדריך פשוט להעלאת "ניהול קופות צדקה" לכתובת אינטרנט קבועה, כדי שתוכלו לפתוח אותה מהנייד כמו אפליקציה ולשתף אותה עם המתרימים.

## שלב 1 — פתיחת חשבון GitHub (חינמי)

1. גשו ל־ [github.com](https://github.com)
2. לחצו **Sign up**, הזינו אימייל, סיסמה ושם משתמש
3. אשרו את המייל שיישלח אליכם

## שלב 2 — יצירת "מאגר" (Repository) חדש

1. אחרי ההתחברות, לחצו על ה־**+** בפינה הימנית העליונה → **New repository**
2. תחת "Repository name" הזינו שם באנגלית, לדוגמה: `kupot-tzedaka`
3. ודאו שמסומן **Public**
4. לחצו **Create repository**

## שלב 3 — העלאת קבצי האפליקציה

1. בעמוד המאגר שנפתח, לחצו על הקישור **uploading an existing file**
   (או: **Add file → Upload files**)
2. פתחו את תיקיית "קופות צדקה" במחשב שלכם, סמנו **את כל הקבצים והתיקיות** בפנים (index.html, manifest.json, sw.js, css, js, icons) וגררו אותם לתוך הדפדפן
3. גללו למטה ולחצו על הכפתור הירוק **Commit changes**

> חשוב: מעלים את **התוכן** של התיקייה (הקבצים עצמם), לא את תיקיית "קופות צדקה" כתיקייה עוטפת.

## שלב 4 — הפעלת GitHub Pages

1. בעמוד המאגר, לחצו על **Settings** (בתפריט העליון)
2. בתפריט הצדדי משמאל לחצו על **Pages**
3. תחת "Build and deployment" → "Source" בחרו **Deploy from a branch**
4. תחת "Branch" בחרו **main** ו־ **/ (root)**, לחצו **Save**
5. חכו כדקה-שתיים, רעננו את הדף — תופיע כתובת ירוקה בסגנון:
   `https://YOUR-USERNAME.github.io/kupot-tzedaka/`

זו הכתובת הקבועה של האפליקציה שלכם.

## שלב 5 — התקנה על הנייד

1. פתחו את הכתובת שקיבלתם בדפדפן של הנייד (Safari באייפון, Chrome באנדרואיד)
2. **אייפון:** לחצו על כפתור השיתוף (הריבוע עם החץ) → **הוספה למסך הבית**
3. **אנדרואיד:** יופיע באנר "הוספה למסך הבית", או דרך תפריט שלוש הנקודות → **התקן אפליקציה**

עכשיו יש לכם אייקון על מסך הבית שנפתח כמו אפליקציה רגילה.

## עדכון האפליקציה בעתיד

אם תרצו לשנות משהו בעתיד — פשוט חוזרים למאגר ב־GitHub, נכנסים לקובץ הרצוי, לוחצים על עיפרון העריכה (Edit), עורכים, ושומרים (Commit changes). השינוי יופיע באתר תוך דקה.

## חשוב לדעת

- **הנתונים עצמם** (קופות, מחזיקים, אסיפות) **לא** נשמרים ב־GitHub — הם נשמרים במכשיר של כל מי שמשתמש באפליקציה. זה עובד מצוין למכשיר אחד.
- אם כמה מתרימים צריכים לראות את **אותם** נתונים במכשירים שונים, יש להפעיל את הסנכרון האופציונלי דרך Supabase, במסך **הגדרות** בתוך האפליקציה.
- מומלץ לייצא **גיבוי** מדי פעם דרך מסך ההגדרות → "ייצוא גיבוי".
